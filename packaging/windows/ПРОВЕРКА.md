# Проверка Melos на Windows

Портативная версия: `dist/Melos-windows-x64.zip` (папка с `Melos.exe` и Java внутри) или один файл `dist/Melos.exe` (распаковывается в `%LOCALAPPDATA%\warp` при первом запуске).

## Первый запуск

- [ ] `Melos.exe` стартует, в таскбаре — иконка Melos (не Java-чашка), чёрной консоли рядом нет.
- [ ] **Без своего Chromium** (первый вход): при нажатии «Войти» сверху окна — шкала «Скачиваю Chromium для входа» с процентами, не тосты.
- [ ] **Без VLC**: на главной — карточка «Melos не нашёл VLC»; кнопки «Найти на ПК» и «Установить VLC» (открывает страницу VLC под Windows). В настройках, раздел «Звук», — предупреждение с теми же кнопками. Попытка включить трек — тост про VLC, приложение не зависает.
- [ ] Установить VLC 3 x64 → «Найти на ПК» → карточка исчезает, в настройках — «VLC … — звук через него», трек играет (перезапуск не нужен).
- [ ] **«Звук через Melos»**: если вывод не поднялся — не тишина, а тост «играю напрямую через VLC» и звук есть; в логе строка `вывод через Melos недоступен`.

## Плеер

- [ ] Поиск, «Треки со всех площадок», волна Яндекса — играют; перемотка, пауза/плей (в т.ч. после переключения вкладок), эквалайзер, громкость.
- [ ] Кнопки звука на клавиатуре/наушниках — вне объёма (пока не работают, это ожидаемо).
- [ ] «Сохранить на устройство…» — открывается выбор папки, трек сохраняется с тегами и обложкой.

## Вход в сервисы

- [ ] Яндекс/SoundCloud: кнопка «Войти» открывает окно входа (JavaFX WebView), после входа — «Вход выполнен», лайки подтянулись.
- [ ] VK: вход и «Моя музыка».

## Окно и рендер

- [ ] Нативный заголовок: свернуть/развернуть/закрыть, перетаскивание, Snap-раскладки (Win+←/→), контент не уехал вверх (нет лишнего отступа).
- [ ] Минимальный размер окна соблюдается; при 125 %/150 % масштабе текст и кнопки не расползаются.
- [ ] Нет белого окна при запуске (рендер DIRECT3D; для сравнения можно запустить с `-Dskiko.renderApi=OPENGL` в Melos.l4j.ini).

## Путь пользователя

- [ ] Настройки лежат в `%APPDATA%\Melos`; после перезапуска очередь и трек восстанавливаются.
- [ ] Загрузки по умолчанию — `Музыка\Melos`.

## Обновление по кнопке

- [ ] Настройки → «Обновления»: видна текущая версия; кнопка «Проверить обновления» работает.
- [ ] Опубликовать релиз чуть новее установленного (`packaging/publish.sh`, с мака) → при следующем запуске сверху карточка «Доступна Melos X» с «Обновить»/«Позже».
- [ ] «Обновить» → шкала скачивания → «Обновляю — перезапустится» → Melos сам поднялся, версия в настройках поменялась, Chromium/входы/настройки на месте.
- [ ] «Позже» до конца сессии карточку больше не показывает.

## MSI (отдельно)

- [ ] `packaging/windows/build-msi.bat` на Windows-машине (JDK 21 + WiX 3.14) даёт `Melos-1.0.0.msi`; установка ставит ярлык, иконка — Melos, повторная установка поверх — обновление (один upgradeUuid).
