# Melos

**Музыкальный плеер на VLC: внутри — модель Murglar, снаружи — дизайн Chrome crawler.**

Kotlin + Compose Multiplatform Desktop + vlcj: один код для macOS, Windows и Linux.

## Что внутри

- **Хост плагинов Murglar.** Melos реализует API `murglar-plugins` 9.x: сеть, куки, настройки, уведомления, логи. Поэтому он грузит jar-плагины Murglar Desktop (`MURGLAR`, `LYRICS_PROVIDER`, `COVERS_PROVIDER`) из папки плагинов. Встроенные сервисы написаны как такие же плагины (`BaseMurglar` + `BaseNodeResolver`):
  - **Яндекс Музыка**: вход как в Murglar, через окно Яндекс ID в Melos (токен берётся из адреса после входа), или по OAuth-токену; «Моя волна», волны по треку и исполнителю, мои треки, альбомы, исполнители и плейлисты, поиск, лайки, синхронные тексты, MP3 320;
  - **SoundCloud**: поиск без входа (client_id берётся с сайта), волна «похожие», исполнители, альбомы, плейлисты, ссылки; с токеном ещё лайки и лента;
  - **Интернет-радио**: каталог radio-browser.info, больше 50 000 станций; страны и жанры, ICY «что сейчас играет»;
  - **На этом компьютере**: папки из настроек, теги через jaudiotagger, альбомы, исполнители, папки, тексты из `.lrc` и тегов.
- **Плеер (VLC 3 через vlcj).** Очередь с «сыграть следующим», перемешивание, повтор, волны, которые подгружаются сами. Очередь переживает перезапуск. Плюс эквалайзер VLC (пресеты и 10 полос), громкость до 200%, скорость, таймер сна с плавным затуханием. Для плагинов с шифрованием работают `Decryptor` и `data:`-источники.
- **Тексты.** Сначала у сервиса, потом у плагинов-поставщиков, потом в LRCLIB. Караоке с подсветкой строки, клик по строке перематывает.
- **Загрузки.** Шаблон пути, теги, обложка и текст в файл, рядом `.lrc`.
- **Избранное и история** общие для всех сервисов. Если сервис умеет лайки, лайк уходит и в сервис.

## Дизайн из Chrome crawler

Нейтральная тёмная или светлая тема, скругления 20/14/10, токены Motion-Luxe («шёлк», «бархат», «инерция»).

- **Акцент по обложке.** Аналог «палитры под сайт»: цвет перетекает за 420 мс, а от точки статуса расходится волна.
- **Мозг** — `art-net.js` из Chrome crawler, перенесённый один в один: та же модель, рендер и реакции. Под музыку: громкость разгоняет вращение и импульсы, на бит идёт волна, каждая вершина срабатывает на пике своей полосы спектра. При включении трека сеть подключается к месту клика и выкачивает его. В конце трека мозг тянет щупальце к кнопке «следующий» и сам её нажимает.
- **Звёздная сеть из точек.** При появлении прорисовывается от крайнего узла, потом камера отъезжает и зажигается небо. Звук идёт через Melos, поэтому сеть видит спектр: бас качает ядро, лучи дышат своими полосами, на бит от ядра идёт волна. Клик даёт пульс, зажатая кнопка мыши — нити к курсору. Через минуту тишины мозг засыпает. Название нового трека он выводит точками.
- **Перемотка и громкость из точек.** У головки перемотки точки подпрыгивают под спектр.
- Каскадное появление строк, блики на акцентных кнопках.

**Плеер под обложку.** Под включённым треком весь интерфейс берёт три цвета обложки:
- по фону плывут мягкие пятна этих цветов, поверх них редкое точечное поле, по которому на бит проходит волна;
- карточки полупрозрачные;
- мозг переливается градиентом обложки и держит её саму точками в ядре: обложка растекается из центра, дышит басом и вздрагивает на бит;
- вокруг кнопки «играть» кольцо из точек: на бит оно вспыхивает, при загрузке по нему бегут искры;
- любой клик отзывается кольцом точек.

Крупные зоны нажатия (не меньше 44 dp), светлый вторичный текст. На широком окне главная в две колонки, на узком в столбик, сайдбар сворачивается в иконки.

Если звук через Melos заикается, выключите в настройках «Мозг слушает музыку». Тогда VLC играет напрямую, а мозг просто дышит.

## Запуск

Нужны **VLC 3** (videolan.org) и **JDK 17+**. Разрядность JDK и VLC должна совпадать.

```sh
./gradlew :app:run                 # запустить
./gradlew :app:packageDmg          # .dmg (на Windows — packageMsi, на Linux — packageDeb/packageAppImage)
MELOS_NET=1 ./gradlew :app:test   # живая проверка сервисов
```

Клавиши: пробел — пауза, ←/→ — ±5 с, ⌘/Ctrl+←/→ — трек, ⌘/Ctrl+F — поиск, Esc — назад.

Плагины Murglar кладутся в папку `plugins` в каталоге данных: `~/Library/Application Support/Melos`, `%APPDATA%\Melos` или `~/.config/melos`. Затем «Настройки → Плагины Murglar → Перезагрузить».

## Устройство

```
app/src/main/kotlin/melos/
  host/      хост Murglar API: HttpNetwork, настройки, тосты, лог, загрузка jar-плагинов (Services)
  builtin/   встроенные сервисы как плагины Murglar: yandex, soundcloud, radio, local, lrclib
  player/    VlcEngine (vlcj, вывод напрямую или через Java Sound со спектром), Player (очередь), Analyzer (FFT)
  library/   избранное и история (лёгкие слепки треков)
  lyrics/    LRC и поиск текста
  download/  загрузки с тегами
  ui/        тема и движение, мозг, экраны, плеер, листы
```

Отладка: `MELOS_PLAY="sc:запрос"` сразу играет первый результат, `MELOS_OPEN=search:…|settings|eq|lyrics|queue|root:<сервис>/<корень>` открывает нужный экран, `MELOS_VOLUME=10` задаёт громкость.
